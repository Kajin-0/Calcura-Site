# Calcura brand brush

`welcome-brush-corner.webp` is Calcura's own transparent raster paint asset,
copied byte-for-byte from `assets/welcome/welcome-brush-corner.webp` in the
Calcura app's `experiment/main-menu-redesign` worktree. Asset source commit: `121b5e2585803465b31c523e6911dea82c462afb`.
The original asset README identifies it as supplied generated paint. No third-party image
or font is included here.

Used once as a quiet, noninteractive background on the website's home hero.
The integral remains the Calcura logo. No app payload assets are changed.
